live서비스 약관

MAKEPLAY(이하 "운영자")는 라이브 방송 도구 live(이하 "앱")를 운영하면서 아래와 같이 정보를 다룹니다.

1. 받는 정보

  • Google OAuth 토큰 — 앱에 YouTube 채널을 연결할 때 Google 이 발급하는 액세스 토큰과 갱신 토큰
  • YouTube 채널 ID·채널 이름 — 어느 채널에 연결됐는지 보이기 위해
  • 방송 정보 — 앱이 만든 방송의 ID·제목·주소, 방송 스트림 ID·스트림 키

이름·이메일·전화번호·시청자 정보·댓글·구독자 정보는 받지 않습니다.

2. 쓰는 목적

연결한 채널에 라이브 방송을 만들고(제목·설명·공개 범위), 방송 스트림에 묶고, 방송이 끝나면 마무리하는 데에만 씁니다. 요청하는 권한은 https://www.googleapis.com/auth/youtube 하나이며, 이 권한으로 영상 올리기·삭제 등 방송 밖의 일은 하지 않습니다.

3. Google API 서비스 사용자 데이터 정책

앱이 Google API 에서 받은 정보를 쓰고 다른 앱으로 옮기는 것은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 보관과 보호

  • 위 정보는 운영자가 직접 관리하는 방송 서버에만, 그 서버 계정만 읽을 수 있는 파일로 보관합니다.
  • 외부 서버·클라우드로 보내지 않고, 광고·분석에 쓰지 않으며, 제3자에게 팔거나 넘기지 않습니다.
  • 앱의 조종 화면은 운영자 내부망에서 비밀번호로만 열립니다.

5. 보관 기간과 삭제

  • 토큰은 채널 연결을 끊을 때까지 보관하며, 앱에서 연결 끊기를 누르거나 채널을 지우면 바로 지웁니다.
  • Google 계정 › 보안 › 타사 앱 액세스에서 언제든 앱의 권한을 취소할 수 있습니다. 취소하면 앱은 더 이상 채널에 접근하지 못합니다.
  • YouTube 에 만들어진 방송·다시보기는 YouTube 스튜디오에서 관리·삭제할 수 있습니다.

6. YouTube

앱은 YouTube API 서비스를 사용합니다. 앱을 YouTube 에 연결하면 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

Privacy Policy (English)

  • Google API Services User Data Policy: live's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
