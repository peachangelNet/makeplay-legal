live 는 MAKEPLAY 가 자기 YouTube 채널의 라이브 방송을 진행하기 위해 직접 운영하는 방송 도구입니다. 카메라·화면·3D 프린터 카메라를 장면으로 묶어 YouTube 로 내보내고, 방송을 시작할 때 YouTube 에 방송(제목·공개 범위)을 만들고 끝날 때 마무리합니다.

YouTube 와 연결해 하는 일

  • 방송 만들기·스트림 연결·방송 마무리 (YouTube Data API — 라이브 방송)
  • 연결한 채널 이름 확인

영상 올리기·삭제, 댓글, 구독자 정보 등 그 밖의 일은 하지 않습니다. live 는 MAKEPLAY 가 관리하는 채널에만 쓰며 일반에 제공하지 않습니다.

live is a live-streaming tool operated by MAKEPLAY for its own YouTube channels. It composes camera, screen and 3D-printer camera feeds into scenes, sends them to YouTube, and uses the YouTube Data API only to create, bind and complete live broadcasts and to read the connected channel's name. It is not offered to the public.
